#OCR
This repository contains my practice and learning work related to **Optical Character Recognition (OCR)** using Python. It includes experiments with extracting text from images and working with OCR libraries.

## Technologies Used

- Python
- Pytesseract
- Tesseract OCR
- Pillow (PIL)
- Regular Expressions (`re`)

## Project Structure

```text
OCR/
├── day1/
├── day2/
├── day3/
├── images/
├── .gitignore
└── README.md
```

## Features

- Extract text from images using OCR.
- Save extracted text into text files.
- Extract information such as email addresses and dates using regular expressions.
- Practice image processing and text extraction with Python.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/anmolkaur-hub/OCR.git
   ```

2. Navigate to the project directory:

   ```bash
   cd OCR
   ```

3. Create and activate a virtual environment:

   **Windows PowerShell**
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

4. Install the required Python libraries:

   ```bash
   pip install pytesseract pillow
   ```

5. Install **Tesseract OCR** separately and configure its executable path if it is not automatically detected.

## Usage

Run the Python scripts from the relevant folder:

```bash
python your_script.py
```

Replace `your_script.py` with the name of the script you want to execute.
